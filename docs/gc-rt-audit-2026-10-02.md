## データ構造と表示

旧machine_id / column_id / temp_program_idを維持し、row_id、temperature_c、linear_velocity_cm_s、split_ratio、measurement_type、measured_date、verification_status、name_statusと出典を追加した。旧GCの未確認の線速度・splitを推測で30 cm/sなどにせずnullで保持する。

グラフの温度選択は90℃を1項目にまとめ、線速度15/30 cm/sを別選択できる。82℃も同じ温度下で19/20 cm/sを分ける。元の温度プログラムIDは保持し、計画系の条件キーにも線速度を含める。

実測は通常の棒、予測は斜線・破線と各物質の「予測」バッジで区別。予測は初期OFF。実測なしの条件では明示し、ONにして初めて予測を描画する。同一物質・同一条件に実測と予測がある場合は実測を優先する。

RTは小数3桁、短い順。横軸は0から始める。0.150 min以下のRT差は近接情報として表示し、棒のオレンジ線は近接の凡例で説明する。隣接する組だけでなく範囲内の全組を計算する。80℃の酢酸エチル/メタノールは0.041 min。RT差だけから分離の可否を断定しない。

## 82℃ / 19 cm/sの参考予測（13物質）

採用した計算はこの資料に対する独自の局所経験モデルで、メーカーの検証済み予測式ではない。JSON内のprediction属性へ式・参照row_id・補正係数・限界を保存する。

1. 同一物質に82℃20 cm/sの実測がある場合：RTを20/19倍。n-ヘキサン2.633、酢酸エチル3.444。
2. それ以外は同一GC・同一カラムの80℃/90℃・30 cm/sの両実測が揃う既知名のみ対象。`exp(0.8*ln(RT80)+0.2*ln(RT90))`で82℃を局所補間し、30/19倍する。
3. 上記の82℃20 cm/sへの換算値と2実測との比の幾何平均を補正として適用する。

カラム寸法・ホールドアップ時間は未確認、予測精度は未検証。split変更・カラム状態・キャリアガスの違いなどはモデル化しない。SBTや80℃だけに値があるシクロヘキサン等は予測を出さない。予測はピーク位置の参考として標準試料と照合する。自動条件提案・当日プランには予測を渡さない。

実測追加後は `npm run update:rt-estimates` でJSONの予測を更新する。実測を上書きしない。次に `npm test` で照合と予測の一致を検証し、固定の実測fixtureに新しい根拠値を追記する。
