更新手順・使い方

使い方と、管理担当者向けのデータ更新手順です。

1) ページ構成の更新

  • トップメニュー: index.html
  • 共通ミニナビ: assets/js/app.js, assets/css/common.css, assets/css/work-ui.css
  • GC当日プラン: gc-day-plan.html, assets/js/gc-day-plan.js, assets/css/gc-day-plan.css
  • GC条件提案: gc-method-finder.html, assets/js/gc-finder.js, assets/css/gc-finder.css
  • RTライブラリ: gc-rt-library.html, assets/js/gc-rt-library.js, assets/css/gc-rt-library.css
  • STDマスタ: gc-std-master.html, assets/js/gc-std-master.js, assets/css/gc-std-master.css
  • GC係数・ppm計算: gc-calculator.html, assets/js/gc-calculator.js, assets/css/gc-calculator.css

2) 在庫関連更新

  • 品目追加: data/inventory-items.json
  • 発注点変更: data/reorder-rules.json

3) GC当日プランの使い方

  1. gc-day-plan.html を開く
  2. GC開始時刻・段取り余裕時間を入力
  3. 匿名コード（A01等）ごとに物質を選択。作業場が複数ある場合は「作業場を追加」
  4. まとめて候補提案 を押す
  5. 全体プラン（1台候補 / 要相談）と作業場別詳細を確認

4) GC条件提案の使い方

  1. gc-method-finder.html を開く
  2. （任意）機械/カラム/温度条件を指定
  3. 対象溶剤を追加して候補表示
  4. この条件を使う で当日メモへ一時保存（localStorage）

5) RTライブラリの見方

  • 機械・カラム・温度条件・物質名・信頼度で絞り込み可能
  • 要確認または低のみ表示 で重点確認可能
  • RTは短い順表示

6) STDマスタの見方

  • 検索 + 状態 + 信頼度で絞り込み
  • 要確認のみ表示 でレビュー対象を抽出
  • STD値の単位はppm。スマホではカード表示、PCでは表表示
  • 「確定」は登録内容の確認済み。「仮登録」「要確認」は原資料の確認が必要

7) GC係数・ppm計算の使い方

  1. ホーム上部の「GC係数・ppm計算」を開く
  2. 計算カードを選び、よく使う物質または物質選択欄から物質を指定
  3. STD値（ppm）を確認し、当日STDエリアと検体エリアを入力。係数・ppmは自動更新
  4. 「計算結果をコピー」または「CSV保存」で出力
  5. 未登録物質は「STDを手入力する」を使う。繰り返し使う場合だけ端末内候補へ追加

8) 匿名コード運用の注意

  • 公開データは匿名コードのみ（A01形式）
  • 実名対応表をリポジトリに置かない

9) 補足

  • 発注点・在庫データと、GCのRT/STDデータは別管理
  • 外部APIなし・ビルド不要・静的ファイルのみで運用

10) 保存とリセット

  • 在庫・GC計算の入力は同じ端末・ブラウザに保存。別端末には自動同期しません
  • 在庫は入力のたびに自動保存し、保存状態を画面に表示
  • 削除・リセットは確認後に実行。保存したい内容は先にコピーまたはCSVで記録
  • GC計算の更新時は data/gc-calculator-version.json・HTML・CSSのバージョンを揃え、公開画面で確認
